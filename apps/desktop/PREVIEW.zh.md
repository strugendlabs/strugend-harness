# Strugend Harness 测试预览版

此预览版采用琥珀色 Strugend 折带标志，提供四种任务模式。编码模式为默认模式，保留 TypeScript 工具执行方式。求职模式寻找职位、根据真实资料制作简历和求职信，并在您的指示范围内申请。日常模式处理日常事务。修复模式复现问题、修复根因并验证结果。已有任务及已保存的默认模式选择保持不变。

此预览版使用您自己的 API 密钥。计费和 Strugend 托管订阅尚未启用。服务商用量由对应密钥的服务商收费；下载内容不包含任何服务商密钥。

请选择 Windows x64 安装程序、适用于 Apple Silicon 的 macOS arm64 下载，或适用于 Intel 的 macOS x64 下载。这些测试版本没有开发者证书签名；macOS 使用临时签名且未经公证。Windows SmartScreen 或 macOS Gatekeeper 可能要求用户明确确认后才能打开。请使用随附的 SHA256 文件核对下载产物。

在首次设置或设置 → 连接中连接首选编码模型。应用无需密钥即可打开，会保留尚未发送的任务，并在需要模型执行时提示连接。密钥由操作系统加密并保存在本地。

决策支持和文档与数据是可选下载，可在首次设置或设置 → 可选工具中安装，也可跳过并稍后安装。基础应用包含用于编码的 Node.js 和 pnpm；文档包添加 Python、文档库和文档预览引擎。本地决策支持要求至少 8 GiB 内存和足够的可用内存；较小设备独立运行主代理。配置的远程决策支持同样是可选的。此预览版记录实验性决策评审；在模型版本通过质量和任务结果评估前，不向编码模型自动注入建议。决策建议不能替代测试，也不能证明工作已经完成。

浏览器、文件、终端、技能、分组和队列已包含。图记忆和视频工作室标记为即将推出。测试网站交付前请添加 GitHub 和 Vercel 凭据，测试发布流程前必须登录社交账户。应用不包含托管计费服务或共享图数据库。

此预览版没有自动更新功能。后续预览版需手动安装。真实服务商及社交账户流程仍需使用您自己的密钥和账户测试；夹具测试通过并不代表已验证这些服务。
