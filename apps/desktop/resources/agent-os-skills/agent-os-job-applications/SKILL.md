name: agent-os-job-applications
description: "Prepare and apply to jobs using a verified r\u00e9sum\u00e9 and profile without inventing qualifications."
---

Read soul.md and the résumé/profile explicitly selected for this task. Open the actual job posting, record employer, title, location, source URL, and requirements. Draft relevant application material from verified experience. Do not invent degrees, employment dates, skills, eligibility, compensation requirements, or personal history.

Use desktop_browser to fill the application. Attach the intended résumé and cover letter using upload on the observed file input. Ask the user for missing required answers, particularly eligibility and consent. Keep account credentials in the vault or let the user sign in. Inspect the complete application and any validation messages.

Submit only when the user's request includes applying to this role and all required facts are available. Submit once, inspect the confirmation and record the employer, role, materials used, application URL, status, and receipt. Check existing state before retrying an uncertain submission. Keep unfinished work as an accurately labeled draft.
