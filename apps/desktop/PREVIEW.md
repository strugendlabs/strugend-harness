# Strugend Harness test preview

This preview uses your own API keys. Billing and Strugend-managed subscriptions are not enabled. Provider usage is charged by the provider associated with each key; no provider keys are included in these downloads.

Choose the Windows x64 installer, the macOS arm64 download for Apple Silicon, or the macOS x64 download for Intel. These test builds have no developer certificate signature; macOS uses an ad hoc signature and is not notarized. Windows SmartScreen or macOS Gatekeeper may require an explicit user decision before opening them. Check the accompanying SHA256 file against the downloaded artifact.

Open Settings → Intelligence to add your Core key. Decision runs in background Observe mode. Automatic uses optional Impossibl access or bundled multilingual Laya when memory allows. Devices below 8 GiB RAM never load local weights; Core remains available. Other AI providers can be added in Intelligence. Graph memory is disabled and marked Coming soon. Add GitHub and Vercel credentials to test website delivery. Keys are encrypted by the operating system and kept locally. The app does not include a hosted billing service or a shared graph database.

Browser, files, terminal, skills, groups, queues, and Video studio are included. Video rendering requires FFmpeg and FFprobe installed on the machine and available on PATH; restart Strugend after changing PATH. You can also supply absolute executable paths through AGENT_OS_FFMPEG and AGENT_OS_FFPROBE. Social accounts must be signed in before testing posting workflows.

This preview has no automatic updater. Install a subsequent preview manually. Live provider and social-account workflows still require testing with your own keys and accounts; passing fixture tests does not qualify those services.
