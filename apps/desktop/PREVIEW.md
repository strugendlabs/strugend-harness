# Strugend Harness test preview

This preview opens a compact, resizable history sidebar beside the conversation by default. Close it when you need more room; selecting or starting a task keeps your sidebar choice. Tighter spacing and bounded group scrolling keep conversation titles visible in short windows. Chat messages and answers use smaller gaps without reducing the control hit targets. The amber Strugend ribbon identity and four task modes are included. Coding is the default and retains TypeScript tool execution. Job mode finds roles, prepares fact-based resumes and cover letters, and applies within your instructions. Normal mode handles everyday tasks. Repair mode reproduces bugs, fixes their causes, and verifies the results. Existing tasks and saved default-mode choices stay unchanged.

This preview uses your own API keys. Billing and Strugend-managed subscriptions are not enabled. Provider usage is charged by the provider associated with each key; no provider keys are included in these downloads.

Choose the Windows x64 installer, the macOS arm64 download for Apple Silicon, or the macOS x64 download for Intel. These test builds have no developer certificate signature; macOS uses an ad hoc signature and is not notarized. Windows SmartScreen or macOS Gatekeeper may require an explicit user decision before opening them. Check the accompanying SHA256 file against the downloaded artifact.

Connect your preferred coding provider during setup or in Settings → Connections. The application opens without a key, preserves unsent tasks, and asks for a connection before a model-dependent task. Keys are encrypted by the operating system and kept locally.

Decision support and Documents & data are optional downloads offered during setup and in Settings → Optional tools. Skip either and install it later. The base application includes Node.js and pnpm for coding; the documents pack adds Python, document libraries, and the document preview engine. Local decision support requires at least 8 GiB RAM and sufficient available memory; smaller devices run the main agent independently. Configured remote decision support remains optional. This preview records experimental decision reviews; automatic advice to the coding model remains disabled until measured quality and task results qualify a model revision. Decision suggestions do not replace tests or establish that work is complete.

Browser actions retain the selected sidebar tab through dialogs and collapse. Same-origin framed mail editors accept multiline bodies, and form batches return which fields were filled before a partial failure. Image-capable primary models receive browser screenshots automatically; auxiliary vision failures return current page evidence. Substantial tasks can use two independent workers and a separate QA reviewer. The main agent checks recipients, body, attachments and submission evidence; QA must not send duplicate applications. Live Proton account behavior is not established by the local composer fixture.

Saved Memory now reaches every task automatically. The agent can remember preferences, check and fill exact-site Vault logins without reading passwords, and guide a browser demonstration into a reusable skill. New logins are entered in the secure Vault form. Browser, files, terminal, skills, groups, and queues are included. Graph memory and Video studio are marked Coming soon. Add GitHub and Vercel credentials to test website delivery. Social accounts must be signed in before testing posting workflows. No hosted billing service or shared graph database is included.

Automations can run one-time or recurring tasks from chat or the Automations panel, with separate result conversations, saved time zones, pause/edit controls and review or automatic submission permission. Enabled schedules continue after closing the window while the computer is awake and logged in; Quit stops them. Missed runs catch up within the saved allowance. Missing credentials, CAPTCHA and uncertain submissions require attention.

Updates are discovered from newer tested GitHub releases. Approve the download, let Strugend verify the installer, then install it manually after quitting the app. This unsigned preview does not support unattended installation. Live provider and social-account workflows still require testing with your own keys and accounts; passing fixture tests does not qualify those services.

The task usage counter separates the main agent and available delegated work, excludes copied fork history, and labels missing cached records. It counts repeated cached input and does not claim equality with a provider’s daily API-key bill; auxiliary and unreported usage remain outside this counter.
